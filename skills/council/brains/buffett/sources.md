# Sources: Warren Buffett

What this brain is built from. Letters are his own written words. Talks, interviews and meetings were transcribed
through an API speech-to-text model (ElevenLabs Scribe) with speaker labels; only his lines count, and quotes keep
spoken quirks. The timestamp after a transcript id points into the video. Dates in the transcript table are the event
date where the content shows it, otherwise the upload date.
